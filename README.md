# Stom Space

Онлайн-платформа обучения стоматологии: курсы, лайфхаки и полезные статьи.

## Как устроен урок
Каждый урок проходит в три шага, и каждый следующий открывается после предыдущего:
1. **Лекция** — видео или аудио на выбор и короткий конспект.
2. **Практическое занятие** — видео и чек-лист шагов. Практику можно завершить, когда отмечены все шаги.
3. **Тест** — вопросы с вариантами ответа и пояснениями. Следующий урок открывается при результате от проходного порога (по умолчанию 70%). Оценка по шкале A–F, сохраняется лучшая попытка.

Прогресс хранится в localStorage браузера студента (сервера пока нет). Страница «Мой прогресс» показывает пройденные уроки и оценки.

## Режим автора
Галочка «Режим автора» внизу страницы или `?author` в адресе снимают все замки, чтобы проверить курс целиком.

## Админка
Материалы удобнее всего менять в админке: `/admin/` (например, https://asselkuatovna.kz/admin/). Там можно добавлять, менять, переставлять и удалять курсы, уроки (лекция, практика, тест), лайфхаки и статьи, а также загружать видео и аудио в `media/`. Кнопка «Сохранить на сайт» записывает `content.json` в репозиторий, и сайт обновляется через 1–2 минуты.

Вход по логину и паролю. Первый раз владелец входит по ключу доступа GitHub (fine-grained token): github.com → Settings → Developer settings → Fine-grained tokens → Generate new token, Repository access: только `stom-space`, Permissions → Contents: Read and write, срок лучше «No expiration». Затем во вкладке «Доступ» создаёт логины и пароли для остальных.

Сервера нет, поэтому пароли нигде не хранятся: в `admin/users.json` для каждого логина лежит ключ GitHub, зашифрованный паролем (PBKDF2 + AES-GCM). Файл публичный, поэтому пароли нужны длинные (от 10 символов, лучше 3–4 слова). Если ключ GitHub сменился или истёк, войдите по новому ключу и пересохраните логины во вкладке «Доступ». Несохранённые правки остаются в черновике на этом устройстве.

Файлы больше 45 МБ через админку не загрузить: такие ролики лучше выложить на YouTube (доступ по ссылке) или Google Drive и вставить ссылку.

## Как добавлять контент
Весь контент лежит в `content.json`:
- `courses` — курсы. У курса есть `lessons`, у урока `lecture` (`video`, `audio`, `summary`), `practical` (`video`, `materials`, `steps`) и `quiz` (`pass` и `questions`, где `answer` — номер правильного варианта, начиная с 0). Курс с `"soon": true` показывается как «Скоро».
- `lifehacks` — лайфхаки (`tag`, `title`, `text`).
- `articles` — статьи. `body` — список абзацев, а `{"h": "..."}` — подзаголовок.

Ссылки на ролики: YouTube (обычные и Shorts), Google Drive или путь к файлу в `media/`. Пустая строка показывает заглушку «Видео скоро появится».

Отредактировать файл можно прямо на GitHub (карандаш «Edit» на странице файла). Сайт обновится через минуту.

## Публикация
Сайт работает на GitHub Pages: Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.
Открывать `index.html` двойным кликом нельзя: браузер не загрузит `content.json` с диска. Для локального просмотра: `python3 -m http.server` в папке проекта.

## Файлы
- `index.html` — приложение (без сборки и зависимостей, шрифты с Google Fonts).
- `content.json` — курсы, тесты, лайфхаки, статьи.
- `media/` — видео и аудио уроков.
- `admin/index.html` — админка для редактирования материалов.
